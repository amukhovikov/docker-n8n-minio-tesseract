# Tesseract

  Нода HTTP Request

  POST запрос 
  http://tesseract-api:8000/ocr
  в SEND BODY тип n8n binary file, Name=file, Input Data Field Name=data

  GET запрос со ссылкой на файл (например URL minio)
  http://tesseract-api:8000/ocr-by-url?url=.......

# Настройка minio

обращаться к minio по имени контейнера, например http://minio:9000

имена контейнеров пишутся малыми буквами

# интерактивный режим работы с minio

## Скачать Minio client

`docker pull minio/mc`

## 1. Запускаем интерактивную оболочку mc
`docker run --rm -it --network=container:minio --entrypoint sh minio/mc`

## 2. Внутри контейнера выполняем:
```
mc alias set local http://localhost:9000 minioadmin minioadmin
mc ls local/
mc mb local/test 
```

## Видим результат!
`exit`


при создании ноды S3 в N8N установить переключатель Force path style (чтобы имя контейнера было http://minio:9000/container )

при загрузке файла со ссылкой на ранее загруженный объект использовать выражения
- имя загруженного ранее файла {{ $('ReadFile').item.binary.data }}
- ссылка на сгенерированный URL для доступа в s3 {{ $('S3URLCode').json.url }}

при отправке запроса в другой сервис ссылаться на имя файла по ссылке {{ $('ReadFile').item.binary.data.fileName }}
